## 💾 Сохранение данных

### Где хранятся данные?
Все данные сохраняются в **localStorage** браузера:
- Профиль пользователя
- Контакты и клиенты
- Задачи с контактами заказчиков
- Сделки

### Как сохранить в Documents?

**Способ 1: Экспорт в JSON (рекомендуется)**
1. Нажмите на иконку ⚙️ (настройки) в правом верхнем углу
2. Нажмите "Скачать бэкап"
3. Файл `crm-backup-YYYY-MM-DD.json` сохранится в папку "Загрузки"
4. Переместите файл в папку `Documents`

**Способ 2: Экспорт в CSV для Excel**
1. Откройте настройки (⚙️)
2. Нажмите "Контакты в CSV" или "Задачи в CSV"
3. Файл откроется в Excel или Google Sheets

### Восстановление данных
1. Откройте настройки (⚙️)
2. Нажмите "Загрузить бэкап"
3. Выберите ранее сохранённый JSON файл
4. Данные будут восстановлены

## 🖥️ Создание .exe приложения

Для создания десктопного приложения (.exe) используйте **Electron**:

### Шаг 1: Установите Electron
```bash
npm install --save-dev electron electron-builder
```

### Шаг 2: Создайте файл `electron.js` в корне проекта
```javascript
const { app, BrowserWindow } = require('electron');
const path = require('path');

function createWindow() {
  const win = new BrowserWindow({
    width: 1200,
    height: 800,
    webPreferences: {
      nodeIntegration: true,
      contextIsolation: false
    },
    icon: path.join(__dirname, 'icon.png')
  });

  // Для разработки
  // win.loadURL('http://localhost:5173');
  
  // Для продакшена
  win.loadFile(path.join(__dirname, 'dist', 'index.html'));
}

app.whenReady().then(createWindow);

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') app.quit();
});
```

### Шаг 3: Добавьте в `package.json`
```json
{
  "main": "electron.js",
  "scripts": {
    "electron": "electron .",
    "build-exe": "electron-builder"
  },
  "build": {
    "appId": "com.crmpro.app",
    "productName": "CRM Pro",
    "directories": {
      "output": "release"
    },
    "win": {
      "target": "nsis",
      "icon": "icon.png"
    }
  }
}
```

### Шаг 4: Соберите приложение
```bash
npm run build
npm run build-exe
```

Готовый `.exe` файл будет в папке `release/`

## 📝 Использование

### Регистрация
1. Введите номер телефона
2. Укажите ФИО
3. Заполните информацию о компании
4. Нажмите "Войти в систему"

### Создание задачи с контактами заказчика
1. Перейдите в "Задачи и Клиенты"
2. Нажмите "Задача"
3. Заполните название и описание
4. В секции "Контакты заказчика" укажите ФИО и телефон
5. Выберите приоритет и срок
6. Нажмите "Создать"

### Управление сделками
1. Перейдите в "Сделки"
2. Создайте новую сделку
3. Перетаскивайте карточки между колонками для изменения статуса
